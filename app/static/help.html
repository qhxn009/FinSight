金融对话

默认模式。AI 结合广发证券 MCP 工具，提供实时龙虎榜、财务分析、ETF 榜单、指数估值等专业数据。

图表分析

上传 K 线图、财报截图等金融图表图片，AI 将通过视觉模型识别并分析图表内容。

财务分析 gf_quant

支持单个分析、对比分析。覆盖：上市日期、估值、盈利、现金流量表、利润表、资产负债表、资本结构、行业信息、行业均值、行业龙头、行业内市值相近的股票、行业内PE相近的股票、行业前二、申万行业名称等

热门 ETF gf_etfrank

查看当前市场热门 ETF 排行，追踪资金流向与板块热度。包括：涨跌榜、搜索榜、关注榜、换手榜、主力资金榜、净申购榜、溢价率榜、特色榜等多维度统计

龙虎榜 gf_lhb

查询沪深两市龙虎榜数据，了解主力资金动向与热门个股买卖席位。包括上榜统计、营业部排名、资金流向等;可以查询当日和历史数据；

指数估值 gf_windmill

查询主要指数的估值水平（PE/PB 百分位），辅助判断市场高低估。支持：宽基、行业、主题指数估值分位与ETF联动分析

深度思考

支持开启深度思考模式，模型在回答前进行多步推理与逻辑分析，思考过程可折叠查看

MCP工具

自动检测券商 Token 有效性，智能启用/禁用四类金融数据工具

流式响应

基于 SSE 的流式传输，实时展示思考过程与回答内容

开箱即用

纯前端无框架依赖，响应式设计，桌面与移动端均可流畅使用

快速开始

本指南将帮助您快速上手 FinSight，从下载项目到发起第一次 API 调用，只需几分钟即可完成。

项目下载安装

  • 执行pip install -r requirements.txt安装依赖
  • 配置环境变量cp .env.example .env编辑`.env` 文件，填入你的Tavily、GLM、广发证券API Key
  • 启动服务python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
  • 访问http://localhost:8000即可使用服务

基本操作流程

  • 在底部输入框中输入您的问题，点击发送或按 Enter 键。Shift + Enter 换行。
  • AI 会自动调用相关金融数据工具进行分析
  • 思考过程可点击 「思考过程」 折叠面板查看
  • 点击 「新建对话」 开始新的分析会话
  • 对话历史自动保存在本地，刷新页面不会丢失

错误代码

  • 左侧边栏：对话列表管理，点击 ☰ 按钮展开/收起
  • 右侧边栏：功能卡片与快捷操作，点击 ≡ 按钮展开/收起
  • 在平板和手机端，侧边栏自动收起为浮层模式
  • 点击顶部工具栏的 ☀️/🌙 图标切换亮色与暗色模式
  • 主题偏好自动保存到本地，下次打开自动恢复

图片上传

  • 点击输入框左侧的 📷 按钮选择图片
  • 上传图片后自动切换到「图表分析」模式
  • 点击图片预览区的 ✕ 按钮可移除已选图片

开发约定

代码风格
  • 后端：保持现有风格——无注释（遵循项目惯例），使用 logger 而非 print
  • 前端：原生 JS，无框架，DOM 操作为主
SSE 事件格式
所有流式事件必须遵循统一格式，方便前端解析：
typecontent 含义
thinking模型的思考/推理过程
content最终回答文本
error错误信息
 
yield _sse_event({"type": "content", "content": "..."})
yield _sse_done()  # data: [DONE]
错误处理
  • 通过 _friendly_error() 将错误码转为中文
  • 连接断开类错误静默处理（只打 warning 日志）
  • 其他错误 yield error 事件到前端

调试技巧

查看 SSE 原始数据
浏览器开发者工具 → Network → 找到 /api/chat/stream 请求 → Response 面板可以看到实时涌出的 SSE 数据。
或者用命令行模拟：
curl -N -X POST http://localhost:8000/api/chat/stream \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"你好"}],"mode":"finance"}'
模拟 MCP 工具调用
在 .env 中填入无效的 GFZQ_TOKEN，系统会自动降级为无工具模式，模型纯靠自身知识回答，方便调试 LLM 本身。
查看后端日志
uvicorn 运行时终端会输出所有 logger 信息，重点关注：
INFO:FinSight initialized: MCP tools enabled/disabled
INFO:Calling GLM API: model=glm-4.7-flash, tools=yes/no
前端调试
index.html 中有几个全局变量可以直接在 Console 中操作：
messages        // 当前对话消息数组
currentMode     // 当前模式：'finance' | 'vision'
thinkingEnabled // 深度思考开关
conversations   // 全部对话列表
常用问题排查
现象排查方向
页面白屏检查终端是否有 Python 报错；检查 static/ 路径是否正确
API 返回 422请求体格式不对，检查 ChatRequest 模型定义
SSE 连接断开智谱 API Key 是否有效、账户是否欠费、网络是否稳定
工具调用失败GFZQ_TOKEN 是否有效、广发证券 MCP 服务是否可用
前端不渲染检查 Console 是否有 JS 错误；检查 SSE 事件格式是否正确
图片上传无反应检查图片大小是否过大；检查 glm-4v-flash 模型是否可用
调用知识库
通过在大语言模型生成答案之前，先从知识库中检索相关知识，然后将相关知识作为背景信息输入给大模型，有效地提升内容的准确性和相关性。

构建知识库

用于管理知识文件，支持上传多个文件，并通过知识库 ID 后进行关联调用。知识库最大容量为 1G。

对话调用关联知识库

创建知识库后，您获得一个知识库 ID。调用模型服务时，传入知识库 ID，使大模型能获取相关内容以响应用户查询。
调用示例
安装 SDK
# 安装最新版本
pip install zai-sdk
# 或指定版本
pip install zai-sdk==0.2.2
验证安装
import zai
print(zai.__version__)
from zai import ZhipuAiClient
client = ZhipuAiClient(api_key="your-api-key") # 请填写您自己的 APIKey
response = client.chat.completions.create(
    model="glm-4.6",  # 填写需要调用的模型名称
    messages=[
        {"role": "user", "content": "你好！你叫什么名字"},
    ],
    tools=[
            {
                "type": "retrieval",
                "retrieval": {
                    "knowledge_id": "your knowledge id",
                    "prompt_template": "从文档\n\"\"\"\n{{knowledge}}\n\"\"\"\n中找问题\n\"\"\"\n{{question}}\n\"\"\"\n的答案，找到答案就仅使用文档语句回答问题，找不到答案就用自身知识回答并且告诉用户该信息不是来自文档。\n不要复述问题，直接开始回答。"
                }
            }
            ],
    stream=True,
)
for chunk in response:
    print(chunk.choices[0].delta.content, end='', flush=True)
