[b][color=Red] 前置准备[/color][/b]

- 一台云服务器（建议最低配置：1核2G，Ubuntu 22.04 / Debian 12 / CentOS 7+）
- 一个域名（可选，但推荐）
- 已注册的 API Key（智谱 GLM + 广发证券 Token）

[b][color=Red] 第一步：服务器基础环境[/color][/b]

[code]
# 更新系统
sudo apt update && sudo apt upgrade -y
# 安装 Python 3.10+ 和 pip
sudo apt install -y python3 python3-pip python3-venv git nginx
# 验证版本
python3 --version
pip3 --version
[/code]

[b][color=Red] 第二步：拉取代码[/color][/b]

[code]
# 创建项目目录
mkdir -p /var/www/finsight
cd /var/www/finsight
# 从 GitHub 克隆（替换为你的仓库地址）
git clone https://github.com/YOUR_USERNAME/FinSight.git .
# 或者上传代码后：
# cd /var/www/finsight
[/code]

[b][color=Red] 第三步：配置环境变量[/color][/b]
[code]
cp .env.example .env
vim .env
[/code]

填入真实的 API Key：
[/code]
GLM_API_KEY=你的智谱APIKey
GFZQ_TOKEN=你的广发证券Token
TAVILY_API_KEY=你的TavilyAPIKey
[/code]

> **安全**：确保 `.env` 文件权限只有项目用户可读：
> [code]
> chmod 600 .env
> [/code]

[b][color=Red] 第四步：安装 Python 依赖[/color][/b]

[code]
# 建议使用虚拟环境
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
# 生产环境额外安装 gunicorn（进程管理）
pip install gunicorn
[/code]

[b][color=Red] 第五步：使用 systemd 管理服务进程[/color][/b]

创建 systemd 服务文件：

[code]
sudo vim /etc/systemd/system/finsight.service
[/code]
写入以下内容：
[/code]ini
[Unit]
Description=FinSight AI Financial Assistant
After=network.target

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/var/www/finsight
Environment=PATH=/var/www/finsight/venv/bin
ExecStart=/var/www/finsight/venv/bin/gunicorn -w 2 -k uvicorn.workers.UvicornWorker app.main:app --bind 127.0.0.1:8000 --timeout 120
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
[/code]

> 说明：`-w 2` 表示 2 个工作进程，可按服务器核数调整。`--timeout 120` 是因为大模型响应可能较慢。

启动服务：

[code]
sudo systemctl daemon-reload
sudo systemctl enable finsight
sudo systemctl start finsight

# 查看状态
sudo systemctl status finsight

# 查看日志
sudo journalctl -u finsight -f
[/code]

[b][color=Red] 第六步：配置 Nginx 反向代理（域名 + HTTPS）[/color][/b]

[b] 6.1 配置 Nginx

[code]
sudo vim /etc/nginx/sites-available/finsight
[/code]

[code]nginx
server {
    listen 80;
    server_name your-domain.com;  # 替换为你的域名
    # 301 跳转到 HTTPS（如果已配置 SSL）
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate     /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;

    # 静态文件（由 Nginx 直接处理，不经过 FastAPI）
    location /static/ {
        alias /var/www/finsight/app/static/;
        expires 7d;
        add_header Cache-Control "public, immutable";
    }

    # API 和主页转发到 FastAPI
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE 关键配置：禁用缓冲，保证流式响应实时推送
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
    }
}
[/code]

启用配置：

[code]
sudo ln -s /etc/nginx/sites-available/finsight /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
[/code]

[b] 6.2 申请 SSL 证书（HTTPS）
[code]
sudo apt install -y certbot python3-certbot-nginx
# 申请证书，certbot 会自动修改 Nginx 配置
sudo certbot --nginx -d your-domain.com
# 证书自动续期（默认已添加定时任务）
sudo certbot renew --dry-run
[/code]

[b][color=Red] 第九步：部署前建议检查的事项[/color][/b]

[b] 9.1 前端链接指向你的网站[/b]

`app/static/index.html` 中有几处链接指向外部网站，如需修改：

- `:32` — `https://www.24krmb.com/forum.php?...`（AI Skill 链接）
- `:37` — `https://www.24krmb.com/forum.php?...`（AI MCP 链接）
- `:66` — `https://www.24krmb.com/`（关于链接）
- `:57` — GitHub 链接

[b] 9.2 help.html 中的提示[/b]

`app/static/help.html` 中提到了"免费、免登陆、无费用"，部署到公网时建议确认这些描述是否仍适用。

[b] 9.3 CORS（跨域）[/b]

当前项目没有配置 CORS 中间件。如果前端和 API 在同域下（通过 Nginx 代理），不会有问题。如果需要前后端分离部署，则需在 `app/main.py` 中添加：

[/code]python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://your-frontend-domain.com"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
[/code]
