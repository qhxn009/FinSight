# 可改进点
config.py 过于简单：Settings.validate() 启动时抛出异常导致服务直接退出，可考虑改为 warning + 继续运行（当前行为是硬性要求配置齐全）

前端代码组织：index.html 有约 350 行 JS 内联在 HTML 中，后续功能增多后可抽取为独立 JS 文件

无日志系统：仅用了 logging.getLogger(__name__) 的基础日志，可考虑接入更完善的日志系统（如按日切割）

无认证机制：API 端点未做鉴权，如果部署到公网需要额外加一层保护

对话持久化只在浏览器端：对话记录存储在 localStorage，清除浏览器数据会丢失；可考虑后端数据库持久化

doc/ 目录内容较杂：包含外部参考文档，其中 云.md、二次开发.md、知识.md 等内容可能更适合放在 wiki 中
